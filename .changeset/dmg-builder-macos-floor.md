fix(dmg-builder): make the macOS 11.0 floor real and enforce it. The bundled `libcrypto`/`libssl` for `_ssl` and `_hashlib` were copied from the runner's Homebrew `openssl@3` (3.6.2, minos 15.0), so part of the runtime required macOS 15; OpenSSL 3.5.9 LTS is now built from source with `MACOSX_DEPLOYMENT_TARGET=11.0` and its license is included in `LICENSES/`. The post-build check in `build.sh` scanned the output folder, which only holds the tarball, so it never inspected a binary; it now extracts each shipped archive and fails on any Mach-O that links a Homebrew library or has a `minos` newer than the deployment target, and on an archive with no Mach-O files at all. CI self-tests the check against fixtures before building. Also bumps Python 3.14.2 → 3.14.10, moves dmgbuild to `cc96fa2` (the CLI `--detach-retries` default goes from 5 to 12, so the bundle file name becomes `dmgbuild-bundle-<arch>-cc96fa2.tar.gz`), pins ds_store 1.3.3, mac_alias 2.2.3 and pyobjc 12.2.2, and lists the installed package versions in `VERSION.txt`.
