fix(fpm): ship the license of every bundled binary. Each bundle now has `LICENSES/MANIFEST.tsv`, which maps every binary to a component, and a `LICENSES/<component>/` directory for each one. Ruby ships `COPYING`, `BSDL`, `LEGAL`, `COPYING.ja` and `GPL` from the checksum-verified Ruby 3.4.12 source tarball; before, it shipped only `COPYING`, downloaded from Ruby's master branch. fpm's `LICENSE` comes from the installed fpm 1.18.0 gem instead of fpm's master branch. On Linux, zlib, libyaml, libffi and GMP ship the `/usr/share/doc/<package>/copyright` file of the Debian package the library was copied from, with the `/usr/share/common-licenses` texts it refers to and a `SOURCE.txt` naming the package version and its source. Racc's `cparse.so` ships the gem's `BSDL`/`COPYING`. On macOS, OpenSSL, zlib, libyaml, GMP and xz ship the license files of their Homebrew formula, with a `SOURCE.txt`. The macOS bundles no longer include GNU readline (GPL-3.0) or ncurses: neither `bin/ruby` nor anything else in the bundle links or loads them, because Ruby 3.4 has no readline extension. The flat `LICENSES/LICENSE.{fpm,ruby,openssl}` files are replaced by this layout. The build now fails if any binary in the bundle, or in the built `.7z`, has no license (`scripts/verify-licenses.sh`).
